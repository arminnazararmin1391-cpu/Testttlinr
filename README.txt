Dragon SMP Shop

این بسته شامل قالب کامل چندفایلی سایت است.
برای اجرای واقعی و امن، باید روی هاست PHP + MySQL آپلود شود.
قبل از انتشار، اطلاعات دیتابیس را در api/config.php وارد کنید و فایل database.sql را ایمپورت کنید.

نکته امنیتی: رمز مدیر نباید داخل JavaScript باشد؛ ورود مدیر باید از دیتابیس انجام شود.
